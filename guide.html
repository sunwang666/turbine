📱 汽轮机效率计算器 - APK 构建指南

⚠️ 为什么不能在这台电脑上直接生成 APK？

当前电脑受企业网络限制，无法下载 JDK（Java编译器）、Android SDK 等构建工具。
但可以用 GitHub Actions 云编译服务 免费自动生成 APK，
全过程只需要浏览器，无需安装任何软件。

方案一：GitHub Actions 云编译（推荐）

全程免费，仅需 GitHub 账号。文件已就绪，跟着做即可。

1️⃣ 注册/登录 GitHub

浏览器打开 https://github.com

• 有账号 → 直接登录
• 没账号 → 点右上角 Sign up，输入邮箱和密码注册（免费）

2️⃣ 创建新仓库

登录后，点击右上角 + 号 → New repository

┌──────────────────────────────────────┐
│ [头像 ▼] [+] ← 点这里 │
│ ├ New repository │
│ ├ New gist │
│ └ New organization │
└──────────────────────────────────────┘

• Repository name 填：turbine-calculator（可任意）
• 不要勾选 "Add a README file"
• 点击底部 Create repository

3️⃣ 上传项目文件

创建后会出现新页面，点击：uploading an existing file

┌──────────────────────────────────────────┐
│ ...or push an existing repository ... │
│ │
│ 📤 uploading an existing file ← 点这里 │
└──────────────────────────────────────────┘

关键：打开文件夹 D:\program files\HermesWorkSpace\android_app

按 Ctrl+A 全选 所有文件/文件夹（包括 .github 文件夹），
拖拽到浏览器上传区域。

在最下面 Commit changes → Commit directly to the main branch → 点击绿色按钮提交。

4️⃣ 找到并触发构建

上传完成后，页面上方有一排标签页：

┌──────────────────────────────────────────────────┐
│ <> Code 🛜 Issues 📋 Pull requests ⚡ Actions ← 点这里 │
└──────────────────────────────────────────────────┘

点击 Actions 标签。

两种情况：

① 如果看到绿色按钮 I understand my workflows, go ahead and enable them
　→ 点击这个按钮启用 workflows

② 如果看到左侧列表有 Build Android APK：

┌──────────────────────────────────────────┐
│ Actions │
│ ┌─────────────────────────────────────┐ │
│ │ All workflows │ │
│ │ 📦 Build Android APK ← 点击这项 │ │
│ └─────────────────────────────────────┘ │
│ │
│ ┌──────────────────────────────────┐ │
│ │ [Run workflow ▼] ← 点这个按钮 │ │
│ └──────────────────────────────────┘ │
└──────────────────────────────────────────┘

• 点击 Build Android APK（左侧列表）
• 再点击右侧 Run workflow 按钮
• 弹出窗口直接点下方的 Run workflow
• 页面刷新，出现一个黄色的 ⚠️ 图标 → 说明构建已开始

5️⃣ 等待构建完成（约 3~5 分钟）

构建中 → 黄色 ⚡ 图标
构建成功 → 绿色 ✅ 图标

可以点击这个 workflow 查看实时日志。

6️⃣ 下载 APK

构建成功后：

┌──────────────────────────────────────────┐
│ ✅ Build Android APK #1 │
│ ┌─────────────────────────────────────┐ │
│ │ Artifacts │ │
│ │ 📦 TurbineEfficiency-APK ← 下载这个 │ │
│ └─────────────────────────────────────┘ │
└──────────────────────────────────────────┘

• 点击 workflow 条目
• 在 Artifacts 部分下载 TurbineEfficiency-APK.zip
• 解压得到 app-debug.apk

7️⃣ 手机安装 APK

• 将 APK 传到手机（微信/QQ/网盘/USB）
• 在手机文件管理器中点击 APK 安装
• 如提示"禁止安装未知来源应用"，去设置中允许即可

安装后打开就是汽轮机效率计算器，完全离线可用 ✅

方案二：PWABuilder 在线生成（备选）

用手机浏览器直接操作

如果您暂时无法访问 GitHub：

1️⃣ 在电脑上先启动临时服务器：

cd D:\program files\HermesWorkSpace\mobile_app
python server.py

2️⃣ 记下电脑的 IP 地址（在 cmd 输入 ipconfig 查看）

3️⃣ 手机和电脑连同一个 WiFi

4️⃣ 手机浏览器打开 http://电脑IP:8000

5️⃣ Chrome 菜单 → 添加到主屏幕 → 安装

安装后和原生 App 一样全屏运行，而且离线可用。
